# 合成範例

本目錄不包含真實商家帳戶或業績。

metrics.synthetic.json 的預期總量：4,000 次曝光、80 次點擊、60 USD 支出、4 次合成轉換、240 USD 合成營收。預期 CTR 2%、CPC 0.75、CPM 15、CPA 15、ROAS 4。這些數字只是程式驗證，不代表 ChatGPT Ads 行業 benchmark。

economics.synthetic.json 是純假設：每單淨收入 60 USD、變動成本 35、目標利潤 10、CVR 2%。導出廣告前貢獻 25、目標 CPA 上限 15、目標 CPC 上限 0.30，不能當作真實出價建議。

mori-offline-plan.md 是品牌工作流程草稿，不包含已核驗商品主張、預算或帳戶權限，不能直接發布。
